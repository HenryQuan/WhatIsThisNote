# Releases

Release notes for each version of WhatIsThisNote, newest first. Each file is
named after the version (`0.1.md`, `0.2.md`, ...) and lists only what changed
in that version.

| Version | Notes | Summary |
| --- | --- | --- |
| 0.2 | [0.2.md](0.2.md) | Accidentals outside the key in the guided theory path. |
| 0.1 | [0.1.md](0.1.md) | First real release: note reading, practice, metronome, chord lab and builder. |

## Adding a release

1. Create `<version>.md` for the new version and list what changed.
2. Add a row to the table above.
3. Tag the commit, e.g. `git tag -a v0.2 -m "WhatIsThisNote 0.2"`, then
   `git push origin v0.2`.
