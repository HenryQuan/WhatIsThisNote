# WhatIsThisNote 0.4

## What's new

- Chords now keep their exact written tones together with their staff
  positions, so altered chords remain correctly spelled on the staff instead
  of being rebuilt from the key signature.
- Added support for double-flat and double-sharp spellings where chord theory
  requires them.
- Chord construction and progression data now live in reusable core services,
  keeping music-theory rules out of the screen layout code.
- The chord builder and chord readout show clearer tone names, inversions and
  suggested tones.

## Fixes

- Keyboard movement, buttons, tapping and dragging now use the same staff
  boundaries throughout the app.
- Chord-builder keyboard movement can no longer move notes beyond the range
  available by dragging.
- Added regression coverage for staff-boundary behaviour and chord voicing.

## Maintenance

- Large production files were split into smaller feature-focused files and
  folders, while generated localization files remain generated.
- Repeated localized section-heading UI was replaced with one small shared
  widget, keeping the implementation simple for future contributors.
