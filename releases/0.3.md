# WhatIsThisNote 0.3

## What's new

- The app is now localized into **eight languages plus English**: Simplified
  Chinese, Traditional Chinese, Japanese, Korean, Spanish, French, German and
  Portuguese. This covers the interface, the guided lessons and the theory
  names (scales, chords, progressions, tempo).
- Added a **Language** option in About. It follows the system language by
  default and saves the choice once the user picks one.
- Solfege names (Do, Re, Mi, ...) are translated too, so the note readout and
  the on-staff label spell them the way each language does.
- The chord lab's inversion buttons (Root, 1st, 2nd, 3rd) are localized.
- The piano now writes the note name on every chord key, e.g. C, E, G and B
  for a Cmaj7, including black keys. The Note tab names the selected chord and
  the chord builder names the stacked notes plus the ideal tones it outlines,
  so it is clear which keys form the chord and which to add next.

## Fixes

- The chord builder's "add above" button now stacks a third above the selected
  note. With C4 selected it adds E4 instead of jumping to D5; "add below" still
  adds A3.
